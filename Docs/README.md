## Historical material

`EveningSample`, the four individual diversity scenes, and the route-capture demo maps were archived from the active project. Their folders under `Docs/` contain earlier captures, instructions and reports for reference; restore the relevant map and configuration before following a historical workflow. The archived maps are not required to read the reports or see the images.
