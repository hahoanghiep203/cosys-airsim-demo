# ThermalGen demo results

These images and the run log were copied from the separate ThermalGen checkout. See `LOCAL_RUN.md` for the upstream revision, setup, and validation details. Its commands apply to that checkout, not this results folder.

- `test_color.png`: input RGB image.
- `test_thermal_uncond.png`: RGB-conditioned output without a style label.
- `test_thermal_cond.png`: M3FD-style output.
- `test_thermal_cond_cfg4.png`: M3FD-style output with guidance scale 4.

These are generated grayscale appearances, not calibrated temperature measurements.
